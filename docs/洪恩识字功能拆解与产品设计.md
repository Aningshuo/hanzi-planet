# 洪恩识字功能拆解 & 「汉字星球」产品设计

> 调研时间：2026-10　｜　调研对象：洪恩识字（iHuman Chinese，3-8 岁儿童识字 App）
> 资料来源：洪恩识字官网（shizi.ihuman.com）、百度百科词条、官方/媒体公开的产品解读文章

---

## 一、先说结论：洪恩识字到底在卖什么

它不是一个"汉字卡片 App"，而是一套**把"认字 → 会写 → 会读 → 会用在句子里"串成闭环的课程系统**，靠三件事撑起来：

1. **单字五步闭环**（玩 → 认 → 练 → 写 → 说）—— 保证每个字都被"多角度加工"过，而不是看一眼就过。
2. **地图式闯关 + 阶段检测** —— 把 1800 字拆成有节奏的路径，每 5 个字回测一次，制造"测试效应"。
3. **子集绘本** —— 用"已经学过的字"编写读物（10 字一本），让识字立刻转化为阅读成就感。

配套的是激励系统（星星、勋章、成长树、AI 学伴）和家长系统（识字报告、时长、护眼、环节开关）。

## 二、功能全景（拆到可实现的颗粒度）

### 1. 课程体系

| 维度 | 洪恩识字 | 说明 |
|---|---|---|
| 字量 | 1800 字 | 覆盖常用字 + 部编版一、二年级识字表 |
| 阶段 | 识字启蒙 200 字 / 生活常用 400 字 / 进阶提升 1200 字 | 按年龄认知与使用频率递进 |
| 组织 | 大地图闯关，单元节点 + 单元字 | 路径可视化，有"旅程感" |
| 单次 | 每课 3-5 分钟，每天 2-3 个新字 | 控制注意力负荷 |
| 检测 | 每学 5 个字一次阶段检测 | 集中回测前一组字 |

### 2. 单字学习闭环：玩、认、练、写、说

| 环节 | 产品里发生什么 | 教学设计意图 |
|---|---|---|
| **玩** | 1 分钟左右的互动小游戏 / 象形动画，先和字形混个脸熟 | 降低进入门槛，建立第一印象与好奇心 |
| **认** | 大字展示 + 拼音 + 字源演变 + 字义讲解 + 组词 | 把"字形"和"字义"绑在一起，追本溯源 |
| **练** | 多种交互反复接触：听音选字、字形辨析、组词配对等 | 在不同任务里多次提取，巩固记忆 |
| **写** | 笔顺演示 → 描红 → 笔顺顺序纠错（写错不显示） | 建立运笔与结构感，AI 笔画纠错 |
| **说** | 字 → 词 → 句逐级开口，跟读 | 从"认得出"走到"用得上" |

### 3. 复习与检测

- 按**记忆曲线**安排复习内容（间隔重复）。
- 阶段检测独立于单字闭环，每 5 字一次。
- 识字报告里能看到"汉字掌握 / 词语掌握 / 句子掌握"等维度。

### 4. 阅读承接：子集绘本

- 130 本原创子集绘本，**10 字一本**，用"词汇复现法"把已学字反复编进故事。
- 构建中文分级阅读体系（L1/L2/L3），循序渐进。

### 5. 拓展内容

- 趣味成语 50 个、古诗词、拼音（另有独立产品「洪恩拼音」）。
- **拍照识字**：拍生活中的字，识别并讲解。
- **生活中的汉字**：场景化识字（超市、路牌等）。

### 6. 激励系统

- 星星（即时反馈）、勋章（成就）、成长树 / 宠物（长期养成）、AI 学伴（陪伴与提醒）。
- 学习报告里的"识字天数 / 连续天数"制造轻量打卡感。

### 7. 家长系统

| 功能 | 细节 |
|---|---|
| 识字报告 | 识字总进度（已认 / 掌握 / 绘本数 / 天数）、上周掌握内容、各环节使用次数、汉字回顾、书写、句子掌握、词语掌握 |
| 时长管理 | 可设每日使用时长（如 45 分钟），到时提醒 |
| 护眼提醒 | 定时提醒远眺 |
| 环节开关 | 可关闭某个环节（如暂时不练书写） |
| 学习速度 | 调整每日新字数 |
| 多端 | 手机 / 平板，账号同步 |

### 8. 教学法依据（决定"为什么这样设计"）

- **测试效应**（Roediger & Karpicke, 2006）：主动回忆比重复阅读更有效 → 所以有阶段检测、听音选字。
- **间隔复习**（Cepeda et al., 2006）：间隔拉长后复习，长期保持更好 → 所以有记忆曲线队列。
- **多认少写**（义务教育语文课程标准 2022）：第一学段认字量远大于写字量 → 所以"写"是书写感知，不是书法训练。
- **手写促进字形识别**（Guan et al., 2021）：所以"写"环节不能省。
- **阅读简单观**（Gough & Tunmer, 1986）：解码 + 语言理解共同决定阅读 → 所以绘本要"字少、句短、结构重复"。

## 三、「汉字星球」怎么做：功能映射表

> 定位：**桌面端（Windows / macOS）离线识字工作台**。不追求 1800 字全量，而是把洪恩识字的**方法论完整跑通**，用 120 字 / 15 单元 / 3 阶段做出一条能从头学到尾的完整路径。

| # | 洪恩识字功能 | 汉字星球实现 | 落地位置 |
|---|---|---|---|
| 1 | 地图式闯关 | 学习地图：3 阶段 Tab + 15 个单元卡片，进度条 + 8 个字格，按单元顺序解锁（学完 75% 解锁下一单元），家长可一键全解锁 | `views/map.js` |
| 2 | 玩：互动引入 | **字宝宝捉迷藏**：泡泡里找目标字，3 轮，干扰字来自同单元/全库 | `lesson.js · buildPlay` |
| 3 | 认：字形字义 | 田字格大字 + 拼音 + 释义 + 组词（可点读）+ 例句（目标字高亮）+ **字形小秘密**（字源/记形口诀）+ 笔画数 | `buildRecognize` |
| 4 | 练：多题型巩固 | 3 题混合：**听音选字 / 看词填字 / 看图识字**，答错即时纠错并高亮正确项 | `buildPractice` |
| 5 | 写：笔顺 + 描红 + 纠错 | hanzi-writer 真实笔顺数据（120 字全量内置）：笔顺动画 → 描红 → **逐笔纠错**（写错不落笔）→ 统计错误次数 | `buildWrite` |
| 6 | 说：字→词→句 | 阶梯式朗读（字/词/句，逐条可听）+ **录音跟读回放**（MediaRecorder，仅本机） | `buildSpeak` |
| 7 | 阶段检测 | **单元小测**：8 题（三种题型轮换），答对计分，满星有勋章 | `startQuiz` |
| 8 | 记忆曲线复习 | 复习中心：1/2/4/7/15/30/60 天间隔队列，答对升级、答错回退；"需要多见面"薄弱字列表 | `store.js · reviewChar` |
| 9 | 子集绘本 | 绘本馆：8 本原创绘本，**按识字量解锁**，逐字拼音（ruby），点字发音，整页朗读，读完 +3 星 | `views/read.js` |
| 10 | 拼音 | 拼音乐园：23 声母 / 24 韵母 / 四声对比，全部可点读 | `views/pinyin.js` |
| 11 | 星星 / 勋章 / 成长 | 成长乐园：宠物（随星星升级 5 个形态）+ 12 枚勋章 + 统计卡 + 最近学会的字 | `views/grow.js` |
| 12 | 识字报告 | 家长中心：已认/掌握/天数/时长 4 项指标 + 近 7 天时长柱状图 + 五环节使用次数 + 薄弱字 | `views/parent.js` |
| 13 | 时长 / 护眼 / 环节开关 | 每日时长（15/30/45/不限，到时温柔拦截）+ 15 分钟护眼提醒 + 五环节独立开关 + 语速/音效 | `app.js · tick` |
| 14 | 家长验证 | 进入家长中心需答一道算术题（防误触） | `parent.js · gate` |
| 15 | 数据管理 | 本地 JSON 档案，支持导出 / 导入 / 重置 | `electron/main.js` |

### 有意没做的部分（以及原因）

| 功能 | 为什么没做 |
|---|---|
| 1800 字全量字库 | 内容量需要专业教研团队校订；本次用 120 字把**方法与体验**做完整，字库是纯数据，后续可直接扩充（`data.js` 一行一个字） |
| 拍照识字 / 生活中的汉字 | 依赖 OCR 与相机，桌面端价值低，且离线包体大 |
| 成语 / 古诗 | 属于"识字后"的第二层内容，当前 120 字阶段还用不上 |
| 云端账号同步 | 定位是**离线单机**，隐私更好（儿童数据不出本机）；需要多设备时用"导出/导入档案" |
| 语音评测（打分） | 需要 ASR + 评分模型；改成"录音回放自我比对"，同样能建立开口习惯，且完全离线 |

## 四、核心算法设计

### 1. 掌握度（mastery 1-5）

```
学完新字            → mastery = 1，安排 1 天后复习
复习答对            → mastery +1（上限 5），间隔进入下一档
复习答错            → mastery -1（下限 1），间隔重置为 1 天
mastery ≥ 3         → 计入"已掌握"
```

### 2. 复习间隔

`REVIEW_STEPS = [1, 2, 4, 7, 15, 30, 60]`（天），按 `reviewCount` 取档；答错即回到第 0 档。
复习中心只展示 `nextReview <= now` 的字，按到期时间排序。

### 3. 解锁规则

- 单元 1 默认开放；第 N 单元在**第 N-1 单元学过 ≥ 75%** 时解锁。
- 家长中心可开启"解锁全部单元"（自由学习模式）。
- 绘本按**累计识字量**解锁（8 / 16 / 24 / 32 / 40 / 56 / 72 / 96 字）。

### 4. 星星经济

学完 1 字 +3，复习答对 1 题 +1，读完 1 本绘本 +3，单元小测按正确率 1-5 星。
星星不做消耗，只作为"成长值"驱动宠物等级（每 25 星升 1 级）。

### 5. 时长统计

前台每秒累计（窗口隐藏/休息状态不计），每 10 秒落盘一次；跨天自动切换 `days[key]` 记录，用于 7 天图表与"有效学习天数"。

## 五、技术架构

```
Electron 32（主进程 + preload 隔离）
├── electron/main.js      窗口、菜单、数据读写 IPC、麦克风权限
├── electron/preload.js   contextBridge 暴露最小 API
└── src/                  纯前端（无构建步骤，classic script）
    ├── index.html
    ├── css/base.css      设计系统（色板/阴影/动效）
    ├── css/views.css     各页面样式
    ├── js/data.js        120 字 + 15 单元 + 8 绘本 + 12 勋章 + 拼音表
    ├── js/store.js       状态、持久化、掌握度与复习算法
    ├── js/sfx.js         Web Audio 合成音效 + 系统 TTS 朗读
    ├── js/ui.js          DOM 工具、Toast、彩带、Modal
    ├── js/views/*.js     六个页面 + 五步课程
    ├── data/strokes.js   120 字笔顺数据（来自 hanzi-writer-data）
    └── data/book-pinyin.js  绘本逐字拼音（构建期用 pinyin-pro 生成）
```

**几个关键取舍：**

- **不用框架**：无构建步骤 → 启动快、打包小、调试直接。
- **朗读用系统 TTS**（`speechSynthesis`，zh-CN 音色）：零音频资源，macOS/Windows 都有中文语音；语速可调（0.65/0.8/0.95）。
- **音效全部合成**（Web Audio 振荡器）：没有版权素材，包体只有几 KB。
- **笔顺数据内置**：`hanzi-writer-data` 的 120 个字 JSON 合并成一个 220KB 的 JS，避免 file:// 下的 fetch 限制。
- **数据落在 userData**：`app.getPath('userData')/hanzi-planet-data.json`，原子写入（tmp + rename）。

## 六、一条完整的学习路径（验收脚本）

1. 首次启动 → 欢迎页 → 「开始第一课」
2. 地图 → 数字启蒙 → 学「一」
3. 玩：泡泡里找到「一」×3 → 认：看字义/组词/例句 → 练：3 题 → 写：看笔顺 + 描红纠错 → 说：跟读录音
4. 结算：+3 星，彩带，字进入 1 天后复习队列
5. 学完 8 个字 → 单元小测 → 满星勋章
6. 第二天打开 → 复习中心出现该字 → 答对 → 间隔变成 2 天
7. 认满 8 个字 → 绘本《小猫和小鸟》解锁 → 点字发音、整页朗读
8. 家长中心 → 算术验证 → 看 7 天时长、五环节次数、薄弱字 → 调时长/关书写环节
